# Storage Estimator - Main version

Purpose
This program estimates how much disk space a group of files will need,
based on the number of files and the average size of each file.

How to Run
1. Make sure Python is installed.
2. Open a terminal in this folder.
3. Run: `python storage_estimator.py`

Example Input and Output
```
=== Storage Estimator ===
Number of files: 100
Average file size: 2.5
Unit (KB or MB): MB
Total size: 256000.00 KB
Total size: 250.00 MB
```
